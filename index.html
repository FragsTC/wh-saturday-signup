⚙️ One-Time Setup — 4 Steps

Do this once, then share the file with your team. Takes about 5 minutes.

1
Go to jsonbin.io and create a free account.
2
After logging in, click API Keys in the top menu → Create Access Key. Copy the key — this is your API Key.
3
Click Bins → Create a Bin. Paste in {} as the content and save. Copy the Bin ID from the URL or the bin detail page.
4
Open this .html file in any text editor (Notepad, TextEdit, VS Code). Find the JSONBIN CONFIG section near the bottom of the file and paste in your API Key and Bin ID. Save the file — the yellow banner disappears and it's live.

Then host it on GitHub Pages and share the URL with your team (see the GitHub Pages instructions in the README if needed).
